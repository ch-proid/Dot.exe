Dot.exe — UI 방향 3안

동일한 P-02 준비 상황을 세 가지 레이아웃으로 구성했습니다. 한국어판 기준이며, 준비 카운트다운은 연구 화면을 열어도 계속 흐릅니다. 각 화면의 연구, 영양 공급, 정화 버튼을 눌러 간단한 동작감을 확인할 수 있습니다.

레퍼런스 적용 원칙 — A는 Game vibe ref + Ref 01의 어두운 올리브·CRT 프레임을 중심으로, B는 UI Ref + Ref 03 + Ref 06의 패널/장비 UI를 절제해서, C는 Ref 02 + Ref 04 + Ref 05의 검은 바탕·네온 발광·후반 긴장감을 평상시 화면에 과하지 않게 가져왔습니다. 현대 서비스명·강한 상시 글리치·밝은 면적 과다는 제외했습니다.
