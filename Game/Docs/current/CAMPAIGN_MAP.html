서사 인과관계 — 절대 순서를 바꾸지 않음

1. SYSTEM연구/환경/위협이 실제 시뮬레이션 규칙을 만든다.
2. BEHAVIOR세포가 화면에서 실제 행동한다.
3. OBSERVATION실제 eventTick과 조건을 기록한다.
4. NARRATIVEEvidence·선행 메일·간격 조건을 판정한다.
5. MAIL이미 일어난 사실만 언급한다.

캠페인 설계 규칙

  • “지능이 탄생했다”는 설명 메일을 보내지 않는다. 플레이어가 증거를 조합해 결론에 도달한다.
  • Miller는 악당이 아니라 결과 중심의 책임자. 이상 현상을 축소 해석하지만 진실을 완전히 알고 숨기는 인물로 만들지 않는다.
  • Park는 처음부터 정답을 아는 인물이 아니다. 오류 검증 → 의심 → 확신의 순서로 플레이어와 거의 함께 도달한다.
  • UNKNOWN의 언어는 깨진 데이터 → 단어 → 어색한 문장 → 완전한 문장으로 발전한다.
  • 같은 고등 행동은 여러 연구 경로로 도달 가능해야 한다. 특정 연구 노드를 서사 정답으로 강제하지 않는다.
  • Checkpoint / FEED / ENVIRONMENT / Trait / Chamber Border처럼 이미 익숙한 기능의 의미를 후반에 뒤집는다.
