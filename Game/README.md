# Dot.exe

세로형 모바일 생명 시뮬레이션 게임 프로젝트.

- 작품명과 극중 시스템명: **Dot.exe**
- 플랫폼: Google Play / App Store
- 화면: 세로 고정
- 기준 디자인: 1080×1920
- 논리 픽셀 화면: 216×384
- 기술 방향: TypeScript + Canvas/WebGL + Capacitor

## 문서

현행 문서:
- `Docs/current/PROJECT_CONTEXT.md` — 프로젝트 맥락·최근 결정·다음 재개 지점
- `Docs/current/CORE_GAME_RULES.md` — 게임 규칙 정본
- `Docs/current/ARCHITECTURE.md` — 시스템 책임과 의존 구조
- `Docs/current/GAME_DESIGN.md` — 게임 경험·기획·서사 방향
- `Docs/current/DEVELOPMENT_SPEC.md` — 구현 명세
- `Docs/current/DEVELOPMENT_PIPELINE.html` — 개발 단계와 관문

과거 검토와 결정 이력은 `Docs/history/`에 있으며 구현 기준으로 사용하지 않는다.
